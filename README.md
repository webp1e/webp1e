- x.inetcom.ru (dropmefiles.com) обнаружена уязвимость IDOR(моё первое сотрудничество)
  
- Собственный vless прокси сервер              - для личного использования
  
- Домашний FTP сервер на debian 11             - для личного использования
  
- serverchichi.online                          - обнаружено 9 критических уязвимостей, всего 28 уязвимостей
  
- forgotten-society.com                        - обнаружены 2 критических CVE (всего найдено 10 уязвимостей)

- сотрудничество с nmap                        - найдена ошибка с неправильным отображением доменного сервиса
